# PLAI 브랜드 → 슬랙 자동 편집 서버 대시보드 UI/UX 개편 가이드

편집봇 이름은 **PLAI**(PLAINOW SI 편집봇)로 확정했습니다. 대시보드 UI/UX를 아래 디자인 시스템에 맞춰 다시 잡아 주세요.

## 에셋 (이 폴더)
| 파일 | 대시보드에서 쓸 곳 |
|---|---|
| `plai-icon.svg` | 파비콘, 사이드바 상단 접힘 상태, 슬랙 봇 프로필 이미지 |
| `plai-lockup.svg` | 사이드바/헤더 로고 (아이콘 + PLAI + SI EDITOR · BY PLAINOW) |
| `plai-edit-horizontal.svg` | 로그인 화면, 상단 헤더 와이드 로고 |
| `plai-edit-stacked.svg` | 로그인/빈 화면 중앙 로고 |
| `plai-wordmark.svg` | 작은 영역의 텍스트 로고 |
| `plai-tokens.css` | 색·라운드·폰트 토큰 — 그대로 import |
| `index.html` / `preview.png` | 브랜드 시트 전체 보기 |

로고 SVG의 글자색은 `currentColor`입니다. 부모 요소의 `color`를 바꾸면 다크 테마는 흰색, 라이트 테마는 검정으로 바뀝니다.

## 디자인 원칙
1. **다크 기본**: 배경 `#0B1413`, 카드 `#111C1B`, 테두리는 틸을 낮은 투명도로. 앱 아이콘의 분위기와 맞춥니다.
2. **틸은 포인트에만**: Primary 버튼, 진행률 바, 활성 탭, 선택 상태에만 `#2FA597` 계열을 씁니다. 넓은 면적에 쓰지 않습니다.
3. **그라데이션은 AI가 일하는 순간에만**: 렌더링 중, AI 편집 진행, 완료 하이라이트에만 `--plai-gradient`와 은은한 glow를 씁니다. 평소 UI는 플랫하게.
4. **편집 타임라인 모티프**: 아이콘의 타임라인 바와 재생 위치 표시를 작업 진행 표시(job progress)와 큐 시각화에 재사용합니다.
5. **✦ 스파클**: AI 자동 처리 결과나 추천 항목 표시에만 아이콘으로 씁니다.
6. **타이포**: 헤드라인과 큰 숫자(KPI)는 굵고 넓은 산세리프(Krona One 계열), 라벨은 대문자 + 자간 넓게, 본문은 Pretendard.

## 권장 화면 구성
- **사이드바**: `plai-lockup.svg`를 쓰고, 메뉴는 대시보드 / 편집 작업 큐 / 슬랙 채널 연동 / 템플릿·프리셋 / 결과물 / 설정 순서.
- **대시보드 홈**: KPI 카드 4개(오늘 처리, 진행 중, 평균 처리시간, 실패) → 실시간 작업 큐(타임라인 바 형태 진행률) → 최근 결과물 썸네일 그리드.
- **작업 상세**: 슬랙 요청 원문 → AI 편집 단계(업로드 → 분석 → 컷 편집 → 자막 → 렌더 → 슬랙 회신)를 단계 표시로 → 결과 미리보기와 재시도 버튼.
- **상태 색**: 성공은 틸, 대기는 회색, 경고는 `#F5B841`, 실패는 `#F0606B`.
